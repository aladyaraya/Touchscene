## 手动仪器测试

自行准备兼容 arm64 JNI 的模拟器或经授权测试机；本包未包含 x86 原生库。
JDK／SDK 与构建保持一致，从 `android/` 运行 `./gradlew :app:connectedDebugAndroidTest`。
全套测试会调用相机、麦克风、相册并在有 Key 时调用合成语音；不要未告知就对用户设备运行。
只做合成 JNI 用例时可选择 `com.insta360.kmpsdk.demo.touchscene.OpenCvNativeInstrumentedTest`。
