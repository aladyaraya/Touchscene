# 发布设计

独立检出目标分支，以其原提交为父提交，仅在独立副本移除旧树并按白名单复制当前工作区。
保留 android 工程原源集；原 SDK 参考源码不编译，影石 assets 不分发。根入口与 docs 面向当前手机版，
不带开发机完整项目记忆。原生库普通 Git 管理，所有模块构建目录均忽略。

源码保护采用由原提交生成的哈希清单和必要布局／文案样本，保留 101／98 和三适配器例外，
正常检查不依赖 Git 历史。CI 无 Key、只读权限、Actions 固定 SHA，只上传测试／Lint 报告。
Lint 仅基线化两个原 Orientation 错误，新增错误阻断。

先本地构建核对，再检查远端未变并普通快进推送；最后核对远端树、CI 与浅克隆。
不重写历史、不更改仓库权限、不创建 Release、不再安装测试机。
