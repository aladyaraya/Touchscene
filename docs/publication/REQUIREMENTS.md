# 分支整理需求

用户已批准本次计划，保持公开仓库，只更新 only-for-android，不改 main 或其他分支。

- R1：当发布新树时，应包含当前工作区未提交的新源码，不得只导出旧 HEAD。
- R2：当队友普通克隆／下载源码时，应能找到配置、构建、检查和交接入口，不依赖开发机路径或私有凭据。
- R3：当提交公开源码时，不应包含 Key、签名、APK、缓存、现场资料、影石素材、Web／ESP32 或无关历史资料。
- R4：当执行整理时，应保持应用算法、UI、模型、包名及库版本不变，保留必要 JNI 与许可证。
- R5：当验证失败或远端发生并发更新时，不应强推、覆盖他人提交或将未验证结果标为通过。
- R6：当发布完成时，应提供可回滚提交、CI／拉取结果及明确的遗留人工验证边界。
