# 统一无障碍操作设计

状态：原开发阶段已批准并实现的设计；先恢复原生依赖，再集成界面与交互。本文不授权超出 `requirements.md` 的改造；本次分支整理不改变此设计，最新验证见 ../../ACCEPTANCE.md。

## 界面规格

用途是减少小目标查找，并保持触觉扫描区固定。视觉延用原项目的工业／工具型高对比方向，不更换主题、字体或图标系统：背景 `#0A0F1D`，主操作 `#00E5FF`，文字 `#FFFFFF`，辅助文字 `#94A3B8`，保留原生 Android 排版。

- 首页：可用内容区整屏上下 50/50，上半手机相机、下半本地图片，分别使用完整半屏入口；不添加第三个可见业务入口。系统栏不计入比例。
- 相机页：`layer_container` 仍为顶部 75%，其地图／实时图容器属性不变；移除 `voice_mic_group` 整组。底部 25% 仅保留一个可操作主按钮，说明可位于按钮文本内，不增加另一可点击区域。
- 原隐藏 `legacy_controls_container` 全部保持原样且继续隐藏；本地图片页布局完整保持原样。
- 新说明使用 `unified_*`；所有原字符串保持原值，已有 `hold_*` 不删除或改值。比例、控件树及资源保护由 Node 源护栏覆盖。

## 输入与状态

| 状态／事件 | 行为 |
|---|---|
| DOWN | 35 ms 一次性短震，等待长按门槛，不立即录音。 |
| <500 ms 内有效 UP | 执行原主按钮短按：LIVE→拍摄冻结描述；EXPLORING→返回 LIVE；录像中只给操作说明。 |
| 持续按住至 500 ms | 停止播报与振动，开始原 `ManualWavRecorder`，不拍摄。 |
| 录音 ≥300 ms 后有效 UP | 结束录音并提交一次 ASR；普通 click 被消费。 |
| 短录音／移出／多指／CANCEL／后台／30 s | 取消且丢弃；不补拍、不提交、不得旧任务误停新录音。 |
| ASR 处理 | 拒绝新录音重入，按原白名单分派命令；完成后再释放待播描述。 |

长按手势使用独立代际和 500 ms 计时；录音 turn 仍使用 `HoldToTalkSession` 的 token、300 ms 最短时长与 30 s 取消上限。录音 I/O 在串行工作线程收尾；只有最新清理代际可解除 busy。授权返回只回到空闲并要求再次按住，不能复用已经结束的手势。页面暂停／销毁使手势、ASR 和描述回调失效。

## 同一张照片的两条输出

```text
语音“拍照” → 一次 takePhoto(saveToGallery=true) → 一个 URI
  → processPhoneImage(同一个 URI) → 原图解码／EXIF／YUV
  → 原 OpenCV → 冻结或刷新地图 → describeLatest → 描述播报
```

保存相册与分析共用同一次快门：`takePhonePhoto` 以 `saveToGallery=true` 调用统一 `requestStillFrame`，后者只登记请求和超时；`captureRequestedStillIfReady` 在相机可拍时先认领代际，再执行唯一一次 CameraX `takePhoto`，回调直接复用返回 URI。相机重绑定的就绪回调可重试认领，但不得新增独立快门。AI 输入仍是归一化原始帧，不是轮廓／边缘可视图。EXPLORING 下命令也可明确刷新，扫描接触冲突仍遵守原地图稳定规则。

“录音”与“摄影／录像”路由到同一 CameraX 录像命令，停止同理，不引入音频文件录制产品。录像开始／完成反馈仍以真实相机回调为准。

## 原生依赖与不变边界

先恢复与现有 OpenCV、目标 ABI 匹配的 `libc++_shared.so` 打包依赖，保留原 OpenCV 二进制及全部算法源码。不能以 catch 后的备用实现输出证明 OpenCV 成功，也不能用阈值原型替代原算法。

基线 101 个 `src/main` 源文件中，只有已经批准的三个云／语音适配器例外；其余 98 个逐文件 exact 比较。该例外集合不因本轮扩大，原 YUV／本地描述代码另有块级保护。生产实现位于 mobile override 或新的窄控制器中。

## 播报与验收策略

保留一个当前地图版本的待播描述；收音、ASR、录音清理、拍摄或命令反馈期间不抢播。按请求代际与地图版本丢弃旧结果；正常回调以及 OEM 漏结束回调都应有有界恢复。首次提示预算按页面进入计算，不因普通刷新或后台恢复重新开启。主动打断已开播语音不增加恢复功能。

验证分四层，不能互相代替：

1. Node：仅保护允许的源码／布局／资源差异，检查一次快门同 URI 的结构。
2. JVM／仪器：手势时间边界、取消与旧回调、真实原生加载及受控 OpenCV 输出、单 URI 链、录像同义、实际布局几何与生命周期。
3. 真机功能：在 PZ261A 重测实际轮廓处理、同图保存、语音拍照和停止录像；记录软件结果，不采集无关私人画面。
4. 人工体验：听到反馈和首次提示、感觉振动、真实 TalkBack、探索及识形任务；未观察不得写通过。

本轮无新增云 API 测试或模型替换需求；本地配置不进 Git、文档、测试报告或公开 APK。产物和报告由主代理登记，不复用旧哈希作为新最终包。
